# Магия прикосновений

Рабочий MVP сайта онлайн-курса Эмиля Баткуллина: публичная главная, личный кабинет, демонстрационная заявка на оплату, ручная модерация доступа и защищённая страница курса.

## Что реализовано

- адаптивная главная страница в стилистике Figma-референса;
- окно «Документы» при первом открытии новой версии документов;
- мобильное меню, клавиатурная навигация, фокус-состояния и `prefers-reduced-motion`;
- три тарифа и сценарий выбора/заявки на оплату;
- вход и выход через защищённую учётную запись ChatGPT (сайт не получает и не хранит пароли);
- профиль участника с именем, телефоном, email, тарифом и статусом;
- Cloudflare D1 для пользователей и платёжных заявок;
- защищённая страница курса: уроки не отдаются до подтверждения доступа;
- админ-панель для подтверждения/отклонения оплаты и выдачи/отзыва доступа;
- страницы политики конфиденциальности, соглашения и оферты;
- все заменяемые ссылки, контакты, реквизиты и источники медиа собраны в `config/site.ts`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run build
npx wrangler d1 migrations apply DB --local --persist-to .wrangler/state
npm run seed:local
npm run dev
```

Локальная авторизация использует тестовую учётную запись `seedy@sites.test`; она также считается локальным администратором.

## Проверки

```bash
npm run typecheck
npm run build
```

## База данных

Схема находится в `db/schema.ts`, сгенерированная миграция — в `drizzle/`. После изменения схемы:

```bash
npm run db:generate
```

Не изменяйте уже применённые миграции. Для новых изменений создавайте следующую миграцию.

## Что заменить перед публикацией

Все значения ниже отмечены `TODO` и собраны в `config/site.ts` или `.env.example`:

1. Настоящие контакты автора и ссылки на социальные сети.
2. Финальные тексты политики, соглашения и оферты.
3. Реальный QR-код, получателя и назначение платежа.
4. Защищённые URL вводного видео и уроков. Платные видео нельзя класть в публичную папку.
5. `ADMIN_EMAILS` — email администраторов через запятую.
6. Подтверждение прав на портрет, постер и выбранные шрифты.
7. Возрастные, юридические и платёжные формулировки для нужной юрисдикции.

## Безопасность

Аутентификацию выполняет платформа ChatGPT, поэтому пароли не передаются приложению и не записываются в базу. Авторизация администратора и проверка доступа к урокам выполняются на сервере для каждого запроса. Статус «Ожидает подтверждения» сам по себе никогда не открывает курс.

Для публичного запуска дополнительно рекомендуется подключить платёжного провайдера с вебхуками, приватное видеохранилище с подписанными ссылками, журнал действий администратора и процедуру удаления пользовательских данных.
